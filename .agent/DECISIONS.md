# 开发决策记录

本文件记录后续实际发生的产品确认及重要工程选择。初始 PRD 已确认结论见 [PRD §0](../docs/PRD_v1.2.md)，未决项见 §12；不复制一份新的产品真相。

建立日期：2026-10-19。本次仅建立 agent 开发规范，未选定具体模型、设备、性能阈值、完整 Must 或私密迁移阶段，未开始 App 开发。

## 记录规则

- 产品确认注明用户确认的日期及当前可核查出处；agent 建议不得标为用户确认。
- 工程选择注明是 agent 的实现决定、适用范围、依据及验证，不冒充 PRD 定案。
- 建议、验证中、已采纳、被替代分别标记；已有决定变化时链接替代记录，保留必要追溯。
- 普通局部可逆实现无需逐条审批或逐条写决策；记录影响产品语义、技术基线、模型分发、数据格式或恢复策略的选择。
- 产品行为变化同步相关约束；需修订 PRD 时保留明确变更依据，不能用代码现状倒推需求。

## D001：项目级约束与 POC 开发目录分离

- 日期：2026-10-19。
- 类型 / 状态：工程组织选择 / 已采纳。
- 依据：用户明确要求“在 .agent 中建立关于整个项目的约束，然后建立一个 poc 的子目录用于 poc 的开发”。
- 决定：`.agent/` 维护全项目及各阶段共用规则；仓库根目录 `poc/` 承载 POC 工程及局部范围、验证要求，继承项目约束。
- 影响：POC 分期从全项目开发约束中移至 `poc/SCOPE.md`；不改变原 PRD，不新增功能授权，不冻结全部 Must 或私密阶段。
- 验证：目录、入口和文档链接检查；本次未初始化 Android 工程，未运行 App 构建或设备测试。
