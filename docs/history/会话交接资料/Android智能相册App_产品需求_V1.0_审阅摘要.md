# Android 智能相册 App｜V1.0 审阅摘要

> 本摘要配套《Android智能相册App_产品需求文档_V1.0_待审阅.md》。本阶段已结束 39 个产品大方向问题，**尚未排开发优先级，也尚未最终签字确认**。

## 一句话定位

**智能相册是主体，生活记忆与 Blog/图文日志是基于照片、视频的延伸能力。** Android 原生、个人自用优先、兼顾未来公开发布。

## 六个核心体系

1. **真实相册与动态虚拟相册双视图**：真实视图映射可访问的物理目录，支持直接移动、重命名和删除；虚拟视图按词条、实体、事件等动态聚合。AI 分类不自动移动原文件。
2. **一次性可视化整理**：选真实目录 → 映射到临时工作区 → AI 建议及人工分类 → 按时间+地点/旅途规划目标目录 → 预览确认 → **移动具体物理来源**。不用内部复制；整理任务不是动态长期同步。
3. **本地优先的增量 AI**：首次授予权限并选择扫描范围后，自动启动预置小模型的媒体索引和初始词条分析；照片可立即浏览，词条逐步补全；历史及新增照片持续增量处理。云端只在授权范围内调用。
4. **词条—实体—事件数据组织**：核心元数据与可扩展词条、层级词条库、实体档案、分层生活事件；三态筛选 ✓/空白/×，同类 OR、异类 AND；AI 推断默认可检索，可切换仅已确认。
5. **统一浏览与智能检索**：统一首页切真实/虚拟；网格按时间组织，双指切 D/M/Y，显示可靠的 Top 地点；上滑信息面板可编辑词条。结构化检索走轻量路径，语义、自然语言和以图搜图按需启用。
6. **媒体关联的个人记忆**：时空旅行推断、分层事件、从任意视图选部分媒体加预设/自定义提示词生成图文日志与 Blog；交互式地图时间轴已确认是高级后续模块。

## 重要不可误改的决定

- 问题 12：**仅实现本地备份恢复**，为远程加密备份与同步留下合理扩展方向，不要求当前实现。
- 问题 15：**仅 C 关键帧+音频视频理解**，不为 D 的完整时序理解专门预留架构。
- 问题 16：**仅 C 反馈纠错**，不为 D 本地模型训练专门预留架构。
- 问题 23：不做本地 App 锁/隐私保险箱；**问题 22 联网授权仍必须保留**。
- 问题 25/26：元数据可在用户明确动作下写回原件；**不内置照片/视频内容编辑器**。
- 问题 27/28：**优先复用系统缩略图，尽量减少内存和存储占用**。
- 问题 33：虚拟相册以**动态词条聚合**为本质，不再独立维护通常意义的静态虚拟相册成员表。
- 问题 38：**选完物理媒体范围立刻渐进处理，绝不因全量 AI 初始化而阻塞相册浏览**。
- **全部开发优先级、实现方案和细节交由后续 Work 阶段与用户共同决定。**

## 本阶段尚未定案的细节

词条父子级筛选是否自动包含后代；重复副本归并/分离规则；Android 权限与操作恢复；具体本地 AI 模型与性能阈值；查询/数据库实现；日志模板及导出规格。这些属于后续 Work 细化，不改变高层产品目标。

## 审阅建议

请优先核查：产品定位、双视图定义、一次性整理的“仅移动”语义、动态虚拟相册、首次处理流程、AI 权限、日志/Blog 延伸功能。如有偏差，提出修改；确认后把完整版交给 ChatGPT Work 继续设计。
