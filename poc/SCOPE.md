# 首个 POC 的范围与开发边界

依据：[完整 PRD v1.2](../docs/PRD_v1.2.md) §0、§12，以及 [MoSCoW / POC 建议](../docs/PRD_v1.2_MoSCoW_POC.md)。全项目约束见 [.agent/DEVELOPMENT_CONSTRAINTS.md](../.agent/DEVELOPMENT_CONSTRAINTS.md)。本文件管理 POC 分期，不缩减完整产品需求。

## 已确认的验证方向

主流程 A：扫描获准照片 → 完全离线内容识别及人物命名关联 → 人工纠错 → 按属性找回 → 重开保留结果。完整 T 整理工具后续验证，不重复询问 A/B 主流程。

可以限定一台目标 Android 设备、一批获准样本、少量属性和基础界面，但不能用联网识别、模拟人物结果或网页演示代替 Android 离线验证。

## 建议范围，尚未整体批准

| 编号 | 候选验证内容 | 细化边界 |
|---|---|---|
| M01 | 获准照片渐进索引与浏览 | 有限来源及目标设备可解码的 JPEG/PNG，时间与可用 GPS；权限失效/缺失状态可见 |
| M02 | 稳定 L 与实际副本 | 小样本字节相同副本关联、来源可查，相似图独立；不执行去重删除，归并冲突规则不暗定 |
| M03 | 属性和虚拟分类 | 最小文本/枚举、名称查找及基本定义管理；复杂层级/别名/合并拆分与引用删除规则不暗定 |
| M04 | 最小离线内容识别 | 预先明确的小类属性和可用本地方案；可复用已建属性库，不提前决定 AI 新定义自动入库 |
| M05 | 离线人物身份关联 | 命名后跨照片匹配、合照多人、未知/不确定及纠错；模型/阈值与交互待验证，不要求手机训练 |
| M06 | 属性查询与核验筛选 | 三态同类 OR、异类 AND、逐项排除；排除未确认 AI 但保留元数据/人工信息 |
| M08 | 持久化及基础任务控制 | 重开保留、渐进分析、失败重试、停止/继续与适度缓存；不等同 T 保存槽或完整备份 |

选择 A 不代表批准表中全部细节。具体开发以用户当前任务和后续确认收敛，不因建立本目录而启动全部功能。

## 阶段待定

M07 私密空间的原件私有迁移、全已知副本覆盖、校验及共享源移除、搜索加密码、禁止在线及系统云备份、卸载删除告知等产品规则已确定；是否进入首个 POC 尚未确定。

不得自动将 M07 纳入或后置，也不能交付仅隐藏标记的旧版替代实现。若获准纳入，完整应用项目 C06 及对应验收。

## 首个 POC 之外的能力

- **Should / Could**：T、真实文件执行与去重、普通视频及更多来源/格式、本地备份/输出、批量管理、基础事件、完整后台和体验增强等，按后续明确任务实现，不因全产品需要而提前搭建全部模块。
- **Won't this POC**：语义/多模态搜索、自动旅行与多层事件推断、图文生成、地图回顾、视频 AI、EXIF 写回、普通云端增强、通用多模态及完整多后端适配。本轮不接在线路径；这些需求仍在完整产品范围内保留。
- **已删除/排除**：遵守项目级 X 范围，如网盘、顶层真实/虚拟双视图、普通分类复制整库、端侧训练、内置编辑器等，不把它们当作自动承诺的后续能力。

## 仍需收敛的实施条件

- 目标设备/系统、获准样本及用于验证的小类属性。
- 实际 Must 子集、属性定义管理的最小边界、未知人物与纠错交互。
- 模型、运行后端、交付资源及许可、匹配阈值、测试方法和资源指标。
- M07 阶段及其未决实施细节。

沿用 PRD V11-Q01—Q22，特别是 Q19/Q21/Q22。可逆技术探索可推进并记录真实结果；触及产品默认语义时继续保留候选状态，不将 agent 提案改为用户确认。
